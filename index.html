Open data for the nonprofit sector

TechSoup Product Bundle

An open, Markdown-first collection of technology donations and discounts available to nonprofits. It's the same dataset that powers TechSoup's Offer Center, published so anyone can build on it.

View on GitHub See the live examples

What's inside

Each product is one Markdown file with structured YAML frontmatter covering the offer, eligibility, and provenance, followed by plain-language detail. There's no database or API to run: the files are the data.

Live examples

Each example filters the bundle into a small JSON feed and renders it with a drop-in web component. Here's the security feed running on this page: 

<script
  src="https://techsoup.github.io/TechSoup-Product-Bundle/examples/security/ts-offer-list.js"
  defer></script>

<ts-offer-list
  src="https://techsoup.github.io/TechSoup-Product-Bundle/examples/security/products.json"
  title="Recommended Security Tools">
</ts-offer-list>

Paste this into any web page to embed the same list.
