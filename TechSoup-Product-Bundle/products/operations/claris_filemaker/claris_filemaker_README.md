## Level 1 (Quick Glance)
Claris FileMaker (an Apple subsidiary) is a low-code platform for building custom apps that run across Windows, Mac, iPad, iPhone, and the web, offered to nonprofits through TechSoup at a discount for 5 users with 3 FileMaker Server licenses. Drag-and-drop app creation requires no coding, and prebuilt add-ons and templates jump-start common needs like contacts, events, and scheduling. It can integrate with SQL data sources and the FileMaker Data API, making it a flexible hub for organizational data.

## Level 2 (Detailed Eligibility Matrix)
- Available to 501(c)(3) nonprofits and public libraries.
- Any budget size is eligible.
- Limit of one annual or perpetual 5-user license per fiscal year (July 1 - June 30).
- Payment model is a discount via TechSoup admin fee: $540 for the 1-year subscription or $1,620 for the perpetual license.
- US organizations only.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** Compatible Windows, Mac, or iOS devices; the bundled FileMaker Server licenses require a server environment for hosted/shared apps.
- **IT Expertise Required:** Moderate. The drag-and-drop builder lowers the barrier, but designing schemas, deploying via FileMaker Server, and using the Data API/SQL integrations assume database-comfortable staff.
- **Maintenance Overhead:** Moderate. Custom apps you build must be maintained by your organization; server hosting adds patching and backup responsibilities.

### Embedded Parameters
- **Security Posture:** Server-hosted deployments centralize data and access; specific controls depend on your FileMaker Server configuration.
- **AI Functionality:** Core ML support enables on-device image classification and object detection within apps you build; no generative AI is core to this offer.
- **Long-Term Sustainability:** The perpetual license option insulates against ongoing fees, but custom-built apps become your organization's responsibility to maintain over time.
