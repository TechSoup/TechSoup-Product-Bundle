## Level 1 (Quick Glance)
Zoner Photo Studio X is an all-in-one Windows application for managing, editing, and sharing photos, offered to nonprofits through TechSoup as a donated one-year subscription (with a renewal product) for one user on any number of computers. It handles automatic import, backup, and folder sorting, lets users organize photos with keywords, labels, ratings, and GPS tags, and provides an edit module with masks, layers, batch editing, HDR, and cloning. The license includes updates and new features during its term.

## Level 2 (Detailed Eligibility Matrix)
- Available only to 501(c)(3) nonprofits and IMLS-listed public libraries.
- Schools, political/legislative activities, government agencies, and hobby clubs are ineligible.
- Unlimited requests.
- Organizations must be willing to provide a case study.
- Donated 1-year license; a $6.00 admin fee applies for both the initial subscription and the renewal.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** A Windows computer; the license covers one user across any number of computers and works with Google Drive, Dropbox, and OneDrive.
- **IT Expertise Required:** Low.
- **Maintenance Overhead:** Low. Updates and new features are included during the license term; a separate renewal product extends it.
