## Level 1 (Quick Glance)
Community Enterprise is open-source, web-based enterprise software bundling 20+ modules to run nonprofit operations, communications, and fundraising from one platform, offered to nonprofits through TechSoup. It pairs a content management system (CMS) with approval-based publishing and a constituent relationship management (CRM) module for tracking individuals and organizations. Built-in donation, e-commerce, and basic double-entry bookkeeping tools let smaller organizations consolidate fundraising and finance in a single tool.

## Level 2 (Detailed Eligibility Matrix)
- Available to 501(c)(3) nonprofits and public libraries.
- Restricted to organizations with an annual budget of $500,000 or less.
- Limit of one product per organization lifetime.
- Payment model is a donation: a $140 TechSoup admin fee, with optional CitySoft-hosted service at $75/month.
- US organizations only.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** Web hosting for the application; if not using the optional $75/month CitySoft hosting, you must provide a server environment capable of running the platform.
- **IT Expertise Required:** Moderate to High. Configuring 20+ modules, the publishing workflow, and customizing the open-source code and design templates assumes web/server administration skills.
- **Maintenance Overhead:** Moderate to High. As self-hostable open-source software, your organization owns updates, security patching, and backups unless you offload hosting to CitySoft.

### Embedded Parameters
- **Security Posture:** Includes an approval-based publishing workflow for content governance; broader security depends on how you host and maintain the open-source deployment.
- **AI Functionality:** None core to this offer.
- **Long-Term Sustainability:** Open-source code with custom templates avoids vendor lock-in, but long-term viability depends on your organization (or CitySoft hosting) keeping the platform patched and current.
