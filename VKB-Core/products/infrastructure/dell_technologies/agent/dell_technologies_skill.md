## Dell Technologies for Nonprofits Expert Knowledge
- Discounts are not automatic at checkout unless the membership passcode is applied; make sure clients enroll (the offer is requested once) and use the passcode so coupons apply automatically. There is a $0 admin fee, and purchases are unlimited.
- U.S. territories are ineligible for this program, so confirm the organization's location before relying on it. For larger device fleets or servers, point clients to the assigned Dell adviser, remote setup assistance, and Dell Payment Solutions financing options.
