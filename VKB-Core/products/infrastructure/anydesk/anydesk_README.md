## Level 1 (Quick Glance)
Offered to nonprofits through TechSoup, AnyDesk provides discounted remote desktop software (Solo and Standard plans) to securely access and control computers and devices from any location. It enables remote access without a VPN, supports cross-platform use across Windows, macOS, iOS, Linux, and Android, and lets IT staff reduce downtime by delivering remote support to colleagues.

## Level 2 (Detailed Eligibility Matrix)
- Open to US 501(c)(3) nonprofits and public libraries, validated through TechSoup.
- Any budget size; one of each subscription per fiscal year.
- The Solo plan covers 1 user and up to 100 unattended devices; the Standard plan covers up to 20 users, 500 unattended devices, and MDM configuration.
- Existing AnyDesk subscribers may request a discounted subscription.
- Subscriptions auto-renew annually at the admin fee.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** The AnyDesk client installed on each device that will be accessed or used to connect; no VPN required.
- **IT Expertise Required:** Low to Moderate. Installing the client and connecting is straightforward; configuring unattended access, multiple users, and MDM (Standard) takes some administrative setup.
- **Maintenance Overhead:** Low. Keeping clients updated and managing the device/user counts within plan limits is the main ongoing work.

### Embedded Parameters
- **Security Posture:** Strong. Sessions use 256-bit encryption and support two-factor authentication.
- **AI Functionality:** None core to this offer.
- **Long-Term Sustainability:** Reasonable, but note the subscription auto-renews annually at the admin fee, so budget for the recurring cost.
