## Level 1 (Quick Glance)
Okta for Good offers 50 free licenses for all workforce identity products (SSO, MFA, Universal Directory) and a 50% discount on additional licenses or advanced products. It serves as the central identity provider to secure access to all cloud applications.

## Level 2 (Detailed Eligibility Matrix)
- Valid 501(c)(3) status verified by TechSoup.
- Some exclusions may apply for heavily affiliated hospital networks.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** Existing directory (e.g., AD, Google Workspace) or willingness to use Okta as the master directory.
- **IT Expertise Required:** Moderate to High. Integrating SAML/OIDC apps requires a strong understanding of identity protocols.
- **Maintenance Overhead:** Moderate. Once set up, it reduces overhead via automated provisioning, but initial mapping is complex.

### Embedded Parameters
- **Security Posture:** FedRAMP, SOC2, HIPAA. Acts as the zero-trust enforcement point.
- **AI Functionality:** Optional AI-driven threat detection (Okta AI) for anomalous login behaviors.
- **Long-Term Sustainability:** High, though deep integration into an org's stack creates high vendor lock-in.
