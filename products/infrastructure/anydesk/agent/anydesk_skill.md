## AnyDesk for Nonprofits Expert Knowledge
- The subscription auto-renews annually at the admin fee, so flag the recurring cost rather than treating it as a one-time purchase.
- Match the plan to scale before buying: Solo caps at 1 user / 100 unattended devices, while Standard supports up to 20 users / 500 unattended devices and MDM config. Note that only one of each subscription is allowed per fiscal year, and existing AnyDesk subscribers may still request a discounted subscription.
