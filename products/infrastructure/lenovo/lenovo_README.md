## Level 1 (Quick Glance)

Lenovo for Nonprofits gives 501(c)(3) nonprofits and public libraries access to a discounted Lenovo product catalog covering desktops, laptops, monitors, tablets, software, and accessories. Through TechSoup, eligible organizations can save up to 25% off Lenovo products, make unlimited purchases, and order tax-exempt. It is a straightforward procurement channel for orgs refreshing or expanding their device fleet.

## Level 2 (Detailed Eligibility Matrix)

- **Eligibility:** Open to 501(c)(3) nonprofits and public libraries.
- **Region:** United States.
- **Budget cap:** Any budget size (no operating-budget ceiling).
- **Quantity limits:** Unlimited purchases; request catalog access once for ongoing access.
- **New-vs-existing:** No new-vs-existing restriction noted.
- **Exclusions / restrictions:** Products may not be resold.
- **Payment model:** Discount offer with a $0 TechSoup admin fee; pay Lenovo directly for products. Tax-exempt ordering is available.

## Level 3 (Implementation & Maintenance Requirements)

- **Technical Prerequisites:** Standard hardware procurement and setup. Purchased desktops, laptops, monitors, and tablets arrive as physical devices that must be unboxed, configured/imaged, and deployed; bundled software requires installation/licensing.
- **IT Expertise Required:** Moderate. Purchasing is simple, but provisioning and deploying endpoints across an organization requires basic IT capacity.
- **Maintenance Overhead:** Moderate. Physical devices require ongoing care, warranty tracking, eventual repair or replacement, and end-of-life disposal.

### Embedded Parameters

- **Security Posture:** General. This is a hardware procurement offer; device security depends on the organization's own configuration and patching practices.
- **AI Functionality:** None core to this offer.
- **Long-Term Sustainability:** Unlimited catalog access with a one-time request supports a repeatable, low-friction device-refresh cycle, though purchased hardware will still age out over time.
