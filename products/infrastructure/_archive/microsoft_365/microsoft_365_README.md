## Level 1 (Quick Glance)

Offered to nonprofits through TechSoup, the Microsoft Cloud Offers provide donated and discounted Microsoft cloud subscriptions spanning Microsoft 365 productivity suites, Office 365 Enterprise plans, Enterprise Mobility + Security, Power BI analytics, and Microsoft Copilot AI. All offers include TechSoup cloud support and license management, helping organizations stand up productivity, communication, mobility, and analytics tooling under one program.

## Level 2 (Detailed Eligibility Matrix)

- Organizations must be a recognized 501(c)(3) nonprofit or equivalent, with public libraries also served; eligibility is validated through TechSoup.
- Available as both donated and discounted cloud subscriptions depending on the plan.
- Cloud license counts vary by plan, covering Microsoft 365, Office 365, Enterprise Mobility + Security, Power BI, and Copilot.
- NTEE Codes: open to nearly all, except some educational and healthcare organizations that have separate tailored programs.
- No maximum budget, though enterprise tiers (E3/E5) and add-ons such as Copilot incur per-user costs.

## Level 3 (Implementation & Maintenance Requirements)

- **Technical Prerequisites:** DNS management access for domain verification; an administrator to manage cloud subscriptions and licensing.
- **IT Expertise Required:** Moderate. Setup of Entra ID and Exchange routing, plus assignment of Microsoft 365, EMS, and Power BI licenses, requires some administrative knowledge; TechSoup cloud support assists with license management.
- **Maintenance Overhead:** Moderate to High, depending on the scale of user lifecycle management and the security policies configured across the cloud subscriptions.

### Embedded Parameters

- **Security Posture:** Enterprise Mobility + Security is included among the offers, providing identity and device-management tooling; higher tiers add advanced protection.
- **AI Functionality:** Microsoft Copilot is included among the cloud offers, bringing generative AI assistance into the Microsoft productivity suite; Power BI adds analytics. AI is available as part of the program rather than core to every plan.
- **Long-Term Sustainability:** High. Subscriptions are managed cloud licenses with TechSoup cloud support, though enterprise tiers and AI add-ons can raise recurring per-user costs over time.
