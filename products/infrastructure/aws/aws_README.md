## Level 1 (Quick Glance)

AWS provides cloud computing credits to help nonprofits scale their infrastructure. Grants range from $1,000 (standard) to $5,000 (larger orgs) per fiscal year.

## Level 2 (Detailed Eligibility Matrix)

- Tiered based on annual operating budget:
  - Budget < $10M: $1,000 Credit ($95 fee)
  - Budget $10M-$50M: $2,000 Credit ($190 fee)
  - Budget > $50M: $5,000 Credit ($475 fee)
- One grant per fiscal year (July 1 - June 30).

## Level 3 (Implementation & Maintenance Requirements)

- **Technical Prerequisites:** Valid AWS account ID.
- **IT Expertise Required:** High (requires cloud architecture knowledge).
- **Maintenance Overhead:** Moderate to High.

### Embedded Parameters

- **Security Posture:** Industry-leading compliance (SOC, HIPAA, FedRAMP).
- **AI Functionality:** Access to Amazon Bedrock (generative AI) and SageMaker (ML).
- **Long-Term Sustainability:** High. Credits cover on-demand services, reducing capital expenditure.
