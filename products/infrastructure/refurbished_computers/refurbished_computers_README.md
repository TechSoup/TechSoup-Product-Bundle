## Level 1 (Quick Glance)

Refurbished Computers is a TechSoup hardware program offering refurbished desktops, laptops, and accessories from manufacturers like Dell, HP, and Lenovo through multiple refurbisher partners (Akooba, InterConnection, IT Xchange, PCs for People, Tech Discounts/Repowered). Available to 501(c)(3) nonprofits and public libraries, it provides refurbished business-grade computers (graded Condition A/B/C), each backed by a one-year warranty covering parts, labor, and shipping, plus free end-of-life R2-certified TakeBack recycling. A 14-day return policy applies.

## Level 2 (Detailed Eligibility Matrix)

- **Eligibility:** Open to 501(c)(3) nonprofits and public libraries.
- **Region:** United States only; U.S. territories are not eligible, and extra charges apply for Alaska and Hawaii.
- **Budget cap:** Any budget size (no operating-budget ceiling).
- **Quantity limits:** Unlimited products.
- **Exclusions / restrictions:** Must accept the Microsoft Registered Refurbisher agreement.
- **Returns:** 14-day return policy.
- **Payment model:** Discount offer paid via a TechSoup admin fee (e.g., $995.00 for a sample desktop); the fee includes shipping.

## Level 3 (Implementation & Maintenance Requirements)

- **Technical Prerequisites:** Physical refurbished computers requiring procurement, unboxing, configuration/imaging, and deployment. Buyers should account for the condition grade (A/B/C) when matching units to use cases.
- **IT Expertise Required:** Moderate. Purchasing is simple, but provisioning refurbished endpoints across an organization requires basic IT capacity, and condition grades mean some inspection/standardization effort.
- **Maintenance Overhead:** Moderate. As refurbished physical hardware, units carry a one-year warranty (parts, labor, shipping) and a 14-day return window; expect a shorter remaining service life than new equipment and plan for the free R2-certified TakeBack recycling at end of life.

### Embedded Parameters

- **Security Posture:** General. Units ship under the Microsoft Registered Refurbisher program; ongoing security depends on the organization's own OS updates and configuration.
- **AI Functionality:** None core to this offer.
- **Long-Term Sustainability:** Refurbished hardware extends device life affordably and includes free certified end-of-life recycling, but refurbished units have a shorter remaining lifespan than new equipment, so plan refresh cycles accordingly.
