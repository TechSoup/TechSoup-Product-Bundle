## Level 1 (Quick Glance)
Offered to nonprofits through TechSoup, Box.org donates a Starter Edition of 10 perpetual licenses with 100 GB of storage, plus a 50% discount on Box Business and Enterprise plans sized for organizations under and over 25 employees. The platform provides cloud file sharing and access from any device, desktop sync for Windows and Mac, and collaboration with version history and tasks.

## Level 2 (Detailed Eligibility Matrix)
- Open to 501(c)(3) nonprofits and public libraries, validated through TechSoup.
- Any budget size; one offer per organization lifetime.
- Educational, healthcare, credit union, government, and benefit organizations are ineligible.
- Existing paid Box subscribers are ineligible.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** None; web-based with optional desktop sync clients for Windows and Mac.
- **IT Expertise Required:** Low. Intuitive for end-users, with straightforward admin controls for setting folder permissions.
- **Maintenance Overhead:** Low. Managing access rights as staff onboard and offboard is the primary administrative task.

### Embedded Parameters
- **Security Posture:** Strong. Includes 256-bit AES encryption and granular permission controls that limit accidental external sharing.
- **AI Functionality:** None core to this offer. Core capabilities cover file sharing, sync, collaboration, and workflow automation via Box Relay.
- **Long-Term Sustainability:** High. Integration with 1,500+ apps reduces lock-in, and the 10 donated perpetual licenses provide a permanent zero-cost baseline for small teams.
