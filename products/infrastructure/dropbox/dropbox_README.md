## Level 1 (Quick Glance)
Offered to nonprofits through TechSoup, Dropbox provides online file sharing, content/team management, and collaboration via discounted annual Standard and Advanced (Business) plans. It delivers encrypted cloud storage with shared team storage (5 TB+), file sharing and collaboration on any file type, and an admin console for managing teams and data.

## Level 2 (Detailed Eligibility Matrix)
- Open to 501(c)(3) nonprofits and public libraries, validated through TechSoup.
- Any budget size; one product per organization lifetime.
- Existing paid Dropbox subscribers are ineligible.
- Requires a minimum of three users.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** A team of at least three users; optional desktop sync clients.
- **IT Expertise Required:** Low to Moderate. End-user file sharing is simple; the admin console for team and data management requires basic administrative familiarity.
- **Maintenance Overhead:** Low. Routine work is managing team membership and shared-folder permissions.

### Embedded Parameters
- **Security Posture:** Strong. Includes file version history and restoration (180 days), ransomware detection and end-to-end encryption (Advanced), SSO integrations, and remote data deletion.
- **AI Functionality:** None core to this offer. Core capabilities cover storage, sharing, collaboration, and admin controls.
- **Long-Term Sustainability:** Solid. The discount is a recurring annual plan, so organizations should budget for ongoing subscription costs beyond the one lifetime offer.
