## Level 1 (Quick Glance)
Tableau Desktop and Tableau Prep Builder are data preparation, analysis, and visualization tools, offered to nonprofits through TechSoup as a donated two-year license for one user, with no programming required. Drag-and-drop data prep and cleaning feed multiple visualization types, including maps, charts, and heat maps. It connects to databases, spreadsheets, Salesforce, and QuickBooks, and produces interactive dashboards and story sequences you can filter and share via Tableau Reader/Public.

## Level 2 (Detailed Eligibility Matrix)
- Available to 501(c)(3) nonprofits and public libraries.
- Restricted to organizations with an annual budget of $5M or less.
- Limit of up to 5 products per fiscal year.
- Foundations and certain religious organizations are ineligible.
- Each license is a 2-year, single-user license.
- Payment model is a donation via TechSoup admin fee: $74 (Desktop) / $37 (Prep Builder).
- US organizations only.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** A compatible desktop computer for Tableau Desktop and Prep Builder; data sources (databases, spreadsheets, Salesforce, QuickBooks) to connect to.
- **IT Expertise Required:** Moderate. The drag-and-drop interface needs no programming, but connecting and cleaning data sources and designing meaningful dashboards assumes data-literate staff.
- **Maintenance Overhead:** Low to Moderate. Desktop software per user; the main upkeep is keeping data connections current and tracking the 2-year license term.

### Embedded Parameters
- **Security Posture:** Sharing is via Tableau Reader/Public; be deliberate about what is published to Tableau Public, which is publicly accessible.
- **AI Functionality:** None core to this offer.
- **Long-Term Sustainability:** The 2-year donated term is generous, but plan for renewal/re-request and note the single-user nature of each license when scaling analytics across a team (up to 5 per fiscal year).
