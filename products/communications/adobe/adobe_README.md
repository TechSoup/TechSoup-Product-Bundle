## Level 1 (Quick Glance)

Adobe partners with TechSoup to give nonprofits both donated and discounted access to its creative software. The program donates Adobe Express memberships for graphics and video and Acrobat Pro/Elements desktop products, while Creative Cloud All Apps (Photoshop, Illustrator, Premiere, and more) and Acrobat Pro DC are available at discounted rates. Members also get stock images, the Adobe font library, and templates.

## Level 2 (Detailed Eligibility Matrix)

- Available to 501(c)(3) nonprofits; Creative Cloud for education (teams) requires 501(c)(3) status, so libraries without it are ineligible for that track.
- Up to 50 donated Adobe Express memberships per fiscal year; donated desktop products are unlimited.
- Acrobat Pro desktop donations are limited to organizations with budgets of $10M or less.
- Requires validation through TechSoup, which charges an administrative fee; donated products carry the fee while discounted Creative Cloud is paid to Adobe.

## Level 3 (Implementation & Maintenance Requirements)

- **Technical Prerequisites:** Computers with sufficient RAM and GPU power to run heavy creative applications; Express and Acrobat web/cloud tools are lighter weight.
- **IT Expertise Required:** Low for deployment (Admin console and Creative Cloud for education centralized admin are straightforward), but Moderate-to-High for end-users operating the full creative suite.
- **Maintenance Overhead:** Low. Automatic updates via the Creative Cloud desktop app handle most patching; perpetual Acrobat Pro 2020 and Elements desktop donations are static.

### Embedded Parameters

- **Security Posture:** Enterprise-grade cloud security with centralized admin via Creative Cloud for education (teams).
- **AI Functionality:** Generative AI for image creation and editing is integrated across the Creative Cloud applications.
- **Long-Term Sustainability:** Medium. The mix of donated Express/Acrobat and discounted Creative Cloud lowers entry cost, but ongoing Creative Cloud renewals remain a recurring per-user expense.
