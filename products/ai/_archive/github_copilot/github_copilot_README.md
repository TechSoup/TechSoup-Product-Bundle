## Level 1 (Quick Glance)
GitHub Copilot is an AI-powered coding assistant that integrates directly into IDEs. Through GitHub's Tech for Social Good and educational programs, eligible nonprofits can receive deeply discounted or free access to GitHub Enterprise, which can unlock Copilot features for internal engineering teams.

## Level 2 (Detailed Eligibility Matrix)
- Open to recognized 501(c)(3) charities.
- Requires verification through the GitHub Tech for Social Good portal.

## Level 3 (Implementation & Maintenance Requirements)
- **Technical Prerequisites:** An active GitHub organization account and compatible IDEs (VS Code, Visual Studio, JetBrains).
- **IT Expertise Required:** High. Geared entirely toward software engineers and DevOps professionals.
- **Maintenance Overhead:** Low. Once seat assignment is configured, the IDE extension handles the rest.
